# Fonts

- **Inter** (variable, wght 400–700) by Rasmus Andersson, https://rsms.me/inter/
- **JetBrains Mono** (variable, wght 400–600) by JetBrains, https://www.jetbrains.com/lp/mono/

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
The woff2 files are the `latin` and `latin-ext` subsets served by Google Fonts
(Inter v20, JetBrains Mono v24), self-hosted so the web app and the Figma plugin make
no font network requests.
